# Founder Focus iOS App

A native iOS application built with SwiftUI, designed specifically for Founders to overcome ADHD paralysis and focus on the ONE most important task.

## Features
- **Distraction-Free Interface:** Dark mode optimized for deep work.
- **Single Task Input:** Forces you to define the single most critical thing to do.
- **Pomodoro Timer:** Built-in 25-minute countdown.

## Getting Started
1. Open this folder in Xcode on a macOS machine.
2. Ensure you have iOS 15.0+ selected as the deployment target.
3. Build and run on the iOS Simulator or your personal iPhone!
